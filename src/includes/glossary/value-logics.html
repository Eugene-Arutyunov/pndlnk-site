Логики создания ценности Три базовых способа, которыми компания создаёт то, чем обменивается.

value chain Артефакт — физический или цифровой объект. Принцип: создаём артефакт, потом обмениваемся.

value shop Артефакт — процесс, в котором клиент участвует совместно. Принцип: договариваемся, потом создаём под клиента.

value net Артефакт — посредничество, доступ к сетям и ресурсам. Принцип: создаём условия для обмена.
