# Команда проекта (роли и функции)

---

> ⚠️ Под проект собирается проектная команда. Команда управляется **триумвиратом**: менеджером, старшим бизнес-аналитиком и старшим исследователем. Они могут привлекать в команду младших специалистов по необходимости. Триумвират также взаимодействует с отраслевыми экспертами.

### Менеджер проекта

- Разработка маршрута проекта
- Организация взаимодействия с командой клиента
- Контроль сроков проекта
- Обеспечение темпа проекта
- Взаимодействие с внешними экспертами

### Старший бизнес-аналитик

- Разработка аналитической модели и клюечевых исследовательских вопросов
- Контроль глубины исследовательских инсайтов
- Формирование итоговых аналитических выводов
- Разработка итоговых артефактов

### Старший исследователь

- Подбор методологии исследования
- Проведение интервью
- Формирование исследовательских инсайтов

### Аналитики

Обработка исследовательских инсайтов

### Исследователи

Поиск информантов, назначение,  проведение интервью

### Журналист проекта

Ведение базы знаний проекта

### Куратор наблюдений

Курирование этнографии

Рекрутинг и устройство наблюдателей

Обработка дневников
